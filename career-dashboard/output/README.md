# Generated resumes

`base/` contains the reviewed base resume, its QA report and two page previews.

`applications/` contains separate version folders created from saved jobs. Each version preserves its own JD, evaluation, research, evidence map and source; compiling adds PDF and previews. Full validation adds qa.json.

`batches/` is the corresponding home for batch artifacts.

These files are results, never sources of candidate claims. A PDF without current passing QA remains a draft.
