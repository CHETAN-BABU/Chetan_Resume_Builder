# Chetan's profile and evidence

Read in this order:

1. `../config/profile.yml` — identity, disclosure preference, targets and resume contract.
2. `evidence.yml` — claim IDs, statuses, approved wording and resume-ready projects.
3. `QUESTIONS-FOR-YOU.md` — specific unresolved details.
4. `PROFILE.md` and `PROFILE-NOTES.md` — readable interpretation and provenance.
5. `sources/` — preserved career narrative, MSc project evidence and portfolio audit.
6. `UPDATES.md` — new notes awaiting incorporation into the registry.

Raw notes retain older recommendations and placeholders to preserve information. They do not override the canonical registry. Generated resumes, job descriptions, employer research and historical packs are never candidate evidence.

The resume template is `../templates/resume-base.tex`. It renders approved evidence; it is not a source document.
